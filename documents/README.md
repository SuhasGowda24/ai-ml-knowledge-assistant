# Source Documents

This folder contains the PDF research documents used as the knowledge source for **DocuMind AI: RAG-Based Document Question Answering System**.

## Documents

- `rag_survey.pdf`
- `rag_pdf_implementation.pdf`

## Usage

These documents provide the source content for document ingestion, text chunking, embedding generation, vector storage, and retrieval-augmented question answering.

Before running the application, ensure the vector store has been built using the provided project scripts and instructions in the main README.

**Note:** The PDFs are included in this repository only if their licences or source terms permit redistribution.
