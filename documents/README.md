# Source Documents

This folder contains the PDF documents used as the knowledge source for DocuMind AI.

The source PDFs are excluded from the Git repository. To run the project, place your permitted PDF documents in this folder, then follow the instructions in the main README to build the vector store.

Expected documents may include:
- `rag_survey.pdf`
- `rag_pdf_implementation.pdf`

**Note:** The PDFs must be available locally before building the knowledge base.
